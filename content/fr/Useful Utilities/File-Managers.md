## GUI

- [dolphin](https://github.com/KDE/dolphin) : Gestionnaire de fichiers par KDE.
- [nautilus](https://apps.gnome.org/en/Nautilus/) : Gestionnaire de fichiers par Gnome.
  - [nautilus-admin-gtk4](https://github.com/MacTavishAO/nautilus-admin-gtk4) : Ouvrir des fichiers avec des privilèges élevés.
  - [nautilus-image-converter](https://gitlab.gnome.org/coreyberla/nautilus-image-converter) : Redimensionner et faire pivoter des images.
  - [nautilus-open-any-terminal](https://github.com/Stunkymonkey/nautilus-open-any-terminal) : Ouvrir des terminaux dans le répertoire sélectionné.
- [nemo](https://github.com/linuxmint/nemo) : Gestionnaire de fichiers par Cinnamon.
  - [nemo-fileroller](https://github.com/linuxmint/nemo-extensions/tree/master/nemo-fileroller) : Extension d'archivage de fichiers.
  - [nemo-terminal](https://github.com/linuxmint/nemo-extensions/tree/master/nemo-terminal) : Fenêtre de terminal intégrée.
- [pcmanfm-qt](https://github.com/lxqt/pcmanfm-qt) : Gestionnaire de fichiers par LXQt.
- [pcmanfm](https://github.com/lxde/pcmanfm) : Gestionnaire de fichiers par LXDE.
- [thunar](https://gitlab.xfce.org/xfce/thunar) : Gestionnaire de fichiers par XFCE.

## TUI

- [lf](https://github.com/gokcehan/lf) : Un gestionnaire de fichiers fortement inspiré de ranger, écrit en Go.
- [nnn](https://github.com/jarun/nnn) : n³ Le gestionnaire de fichiers terminal non-orthodoxe.
- [ranger](https://github.com/ranger/ranger) : Un gestionnaire de fichiers inspiré de VIM pour la console.
- [superfile](https://github.com/yorukot/superfile) : Gestionnaire de fichiers terminal moderne et plutôt élégant.
- [yazi](https://yazi-rs.github.io/) : Gestionnaire de fichiers terminal ultra rapide écrit en Rust, basé sur des E/S asynchrones.
