[aquamarine](https://github.com/hyprwm/aquamarine) is a very light Linux rendering backend library.

It is not a replacement or competitor to any other Wayland compositor library (e.g., wlroots, libweston).
Instead it implements only the low-level KMS, DRM, etc. rendering backends.

## Configuration

Configuration options are passed via environment variables starting with `AQ_` to an app that uses aquamarine (e.g., Hyprland).

### Variables
Environment variables for configuring Aquamarine are listed at [the environment variables page.](../../../configuring/core/environment-variables/)
