## Foreword

For maximum performance using your NVIDIA card, we recommend using the official, proprietary drivers (with the open source kernel modules) if your GPU is modern enough.

Because the official drivers are still proprietary, some issues could arise when using NVIDIA GPUs on Hyprland that we have no control over.
However, the state of the drivers is slowly but surely improving — it's possible to have a well-working setup, almost on par with AMD and Intel GPUs.

## Wiki links

There are no distro-agnostic set of instructions for setting up the NVIDIA drivers.
For the most up to date guide to installing the recommended drivers for your distro / GPU combo, please refer to the NVIDIA wiki page for your distro of choice.
The wiki pages for our officially supported distros are provided below.

- [Arch Wiki](https://wiki.archlinux.org/title/NVIDIA)
- [NixOS Wiki](https://wiki.nixos.org/wiki/NVIDIA)
