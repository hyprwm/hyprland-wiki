## Wayland info

A Wayland compositor is a fully autonomous Display Server, like Xorg itself.
It is **not** possible to mix'n'match Wayland compositors like you could on Xorg with window managers and compositors.
It is also not entirely possible, nor recommended, to try and use all Xorg applications on Wayland.
See [this page](./useful-utilities/) for a list of recommended Wayland native/compatible programs.
